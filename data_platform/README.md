# B — Data & Research Platform

This directory will contain the engineering platform implemented by Codex.

Planned responsibilities:
- fixture and team data ingestion
- odds / Asian handicap / totals snapshots
- append-only market history
- source and bookmaker metadata
- data-quality scoring
- database and migrations
- backtesting
- automatic settlement
- CLV / ROI / calibration statistics
- future browser-based Leisu collector

The data platform does not redefine football-analysis logic; it supplies reliable data and infrastructure to A — Analysis Engine.
